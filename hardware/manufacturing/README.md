# Manufacturing Guide

This document provides specifications for ordering PCB fabrication, assembly, and CNC chassis parts for the Robot Platform.

## PCB Fabrication

### Recommended Vendors

- JLCPCB (budget, fast turnaround)
- PCBWay (higher quality options, flex PCB support)

### Order Parameters

| Parameter | Value |
|-----------|-------|
| Layers | 4 |
| Board dimensions | 120 x 90 mm |
| Board thickness | 1.6 mm |
| Surface finish | ENIG (Electroless Nickel Immersion Gold) |
| Copper weight (outer) | 1 oz (35 um) |
| Copper weight (inner) | 1 oz (35 um) |
| Soldermask color | Green |
| Silkscreen color | White |
| Min trace/space | 0.15 mm / 0.15 mm |
| Min drill | 0.2 mm |
| Via type | Tented vias |
| Impedance control | Yes (see below) |

### Stackup

4-layer controlled impedance stackup:

```
Layer 1 (F.Cu)  — Signal    — 35 um copper
Prepreg         — 0.2 mm    — FR4 (Er ~4.3)
Layer 2 (In1.Cu) — GND plane — 35 um copper
Core            — 1.2 mm    — FR4 (Er ~4.3)
Layer 3 (In2.Cu) — Power plane — 35 um copper
Prepreg         — 0.2 mm    — FR4 (Er ~4.3)
Layer 4 (B.Cu)  — Signal    — 35 um copper
```

Total thickness: ~1.6 mm (including soldermask and silkscreen)

### Impedance Control

| Signal Type | Target Impedance | Trace Width | Gap/Space | Layer |
|-------------|-----------------|-------------|-----------|-------|
| USB 2.0 differential | 90 ohm differential | 0.2 mm | 0.15 mm | Outer (L1/L4) |
| Single-ended signals | 50 ohm | 0.25 mm | - | Outer (L1/L4) |

The USB differential pair (D+/D-) between the USB-C connector and ESP32-S3 must be routed as a 90 ohm differential pair on outer layers with a solid GND reference on Layer 2.

## Assembly (SMT)

### Specifications

| Parameter | Value |
|-----------|-------|
| Assembly type | Lead-free reflow (RoHS) |
| Minimum package size | 0402 (1005 Metric) |
| Stencil thickness | 0.12 mm |
| Solder paste | SAC305 (Sn96.5/Ag3.0/Cu0.5) |
| Reflow profile | Per IPC J-STD-020 |
| Sides | Top side only (bottom has through-hole connectors) |

### Assembly Notes

1. All SMD components are on the top side
2. Through-hole components (connectors, motor headers, sensor headers) are hand-soldered after reflow
3. BNO055 IMU module requires careful placement — observe orientation marking
4. DRV8833 exposed thermal pad must have adequate solder paste coverage for heat dissipation

### JLCPCB Assembly Checklist

- Upload BOM CSV (generated by `generate_bom_placement.sh`)
- Upload CPL (component placement) CSV
- Verify component rotation matches footprint orientation
- Confirm LCSC part numbers match BOM

## CNC Chassis Ordering

### Material and Finish

| Parameter | Value |
|-----------|-------|
| Material | 6061-T6 Aluminum |
| Sheet thickness | 2 mm |
| Surface finish | Black anodize (Type II, 10-25 um) |
| Tolerance | +/- 0.1 mm |
| Edge finish | Deburred, smooth |

### Ordering Notes

- Provide DXF or STEP files from `hardware/structure/`
- Request black anodize after machining
- Specify M3 threaded holes where indicated in drawings
- Motor mount holes must maintain +/- 0.05 mm position tolerance for proper wheel alignment
- All internal corners should have minimum 1 mm fillet (tool radius)

### Recommended Vendors

- PCBWay CNC service
- Xometry
- SendCutSend (for simpler flat parts)
- Local machine shops for prototyping

## File Generation

Use the scripts in this directory to generate manufacturing output files:

```bash
# Generate Gerber and drill files
./generate_gerbers.sh

# Generate BOM and placement files for assembly
./generate_bom_placement.sh
```

Output files are written to `hardware/manufacturing/output/`.

## Quality Checks

Before ordering, run the validation scripts:

```bash
# Run DRC on PCB layout
../validation/kicad_drc.sh

# Validate hardware consistency across firmware and schematic
python3 ../validation/validate_hardware.py

# Check BOM against schematic
python3 ../validation/check_bom_schematic.py
```
