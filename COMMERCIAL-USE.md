# Commercial Use

## You Are Free to Use This Commercially

This project is available under permissive open-source licenses:

- **Software**: Apache License 2.0
- **Hardware**: CERN Open Hardware Licence v2 — Permissive
- **Documentation**: Creative Commons Attribution-ShareAlike 4.0

**No additional commercial license is required.** You may freely use, modify,
manufacture, and sell products based on this project.

## What Is Required

Attribution — include a notice in your product (e.g. "About" page, documentation,
or packaging) that references this project:

> This product is based on the open-source [3we Robot Platform](https://github.com/telleroutlook/3we-robot-platform).

The [`NOTICE`](NOTICE) file must be included with any distribution of the software,
per Apache 2.0 Section 4(d).

## FAQ

**Q: Can I build a product on top of this platform and sell it?**
A: Yes. The open-source licenses explicitly allow this. Attribution is the only requirement.

**Q: Do I need to open-source my modifications?**
A: No. Apache 2.0 and CERN-OHL-P v2 are both permissive — you may keep modifications proprietary. You must retain copyright notices and the NOTICE file.

**Q: Can I remove the PCB silkscreen text?**
A: CERN-OHL-P v2 Section 3.1 requires that notices are preserved. If you substantially redesign the PCB, add equivalent attribution elsewhere.
