# Commercial Use

## You Are Free to Use This Commercially

This project is available under permissive open-source licenses:

- **Software**: Apache License 2.0
- **Hardware**: CERN Open Hardware Licence v2 — Permissive
- **Documentation**: Creative Commons Attribution-ShareAlike 4.0

**No additional commercial license is required to use the open-source version.** You
may freely use, modify, manufacture, and sell products based on this project with
attribution only.

## What Is Required

Attribution — include a notice in your product (e.g. "About" page, documentation,
or packaging) that references this project:

> This product is based on the open-source [3we Robot Platform](https://github.com/telleroutlook/3we-robot-platform).

The [`NOTICE`](NOTICE) file must be included with any distribution of the software,
per Apache 2.0 Section 4(d).

## Commercial Licensing (Optional)

We offer an optional commercial license for organizations that prefer:

- **No attribution requirement** — use the platform without referencing this project
- **Access to proprietary components** — AI models, cloud services, advanced web panel
- **Dedicated support with SLA guarantees**
- **Custom integration and consulting services**
- **Patent indemnification and legal certainty**

Commercial licenses are priced per unit and are suitable for organizations deploying
at scale that need additional assurances beyond what the open-source license provides.

Contact: commercial@robot-platform.org

## Sustainability Model

This project uses a **CLA + Dual Licensing** model (similar to Qt, GitLab, and other
successful open-source projects):

- The **open-source version** remains 100% free under Apache 2.0 / CERN-OHL-P v2 —
  forever. This will never change.
- **Commercial licensing revenue** funds continued development, hardware revisions,
  and community support.
- Contributors sign a [CLA](CLA-INDIVIDUAL.md) granting the maintainers the right to
  offer dual licenses. Contributors retain full ownership of their work, and their
  code always remains available under the open-source license.

We believe this model keeps the project sustainable long-term while ensuring that
the open-source community always has full access.

## FAQ

**Q: Can I build a product on top of this platform and sell it?**
A: Yes. The open-source licenses explicitly allow this. Attribution is the only requirement for the open-source version.

**Q: Do I need to open-source my modifications?**
A: No. Apache 2.0 and CERN-OHL-P v2 are both permissive — you may keep modifications proprietary. You must retain copyright notices and the NOTICE file.

**Q: When would I need a commercial license?**
A: Only if you want to remove the attribution requirement, need access to proprietary components, or want SLA-backed support. The open-source version is fully functional without a commercial license.

**Q: Does the CLA mean my contributions become proprietary?**
A: No. Your contributions are always available under the open-source license (Apache 2.0 / CERN-OHL-P). The CLA additionally allows the maintainers to include your code in the commercial offering. You retain full ownership.

**Q: Can I remove the PCB silkscreen text?**
A: CERN-OHL-P v2 Section 3.1 requires that notices are preserved. If you substantially redesign the PCB, add equivalent attribution elsewhere. A commercial license removes this requirement.
